## Overview

광주은행 웹/앱 구축 및 웹 접근성 프로젝트에서 모바일 웹/앱 리뉴얼 퍼블리싱과 웹 접근성 적용을 맡았습니다. 디플러에서 프리랜서로 참여했습니다.

## Context

- 금융기관 웹/앱 리뉴얼 프로젝트였습니다.
- 웹 접근성 기준(WCAG 2.1)을 충족하고 웹 접근성 마크를 받는 것이 목표 중 하나였습니다.

## Role

웹 퍼블리셔로 다음을 담당했습니다.

- 모바일 웹/앱 리뉴얼 퍼블리싱
- 웹 접근성 기준 적용

## Action

1. 이미지와 아이콘에 대체 텍스트를 제공했습니다.
2. 마우스 없이도 모든 기능을 쓸 수 있도록 키보드 내비게이션을 구성했습니다.
3. 텍스트와 배경의 명도 대비를 기준에 맞췄습니다.
4. HTML5, CSS3, JavaScript, jQuery로 화면을 구현했습니다.

## Result

- 웹 접근성 마크를 획득했습니다.

## Lessons Learned

- 접근성은 마무리 단계에서 덧붙이기보다 마크업 단계부터 함께 처리해야 수정 비용이 적다는 점을 경험했습니다.
- 이 경험이 이 포트폴리오에서 접근성을 구현 단계에 함께 처리하는 기준이 되었습니다.
