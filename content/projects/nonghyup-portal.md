## Overview

범농협 운영지원센터 2.0 리뉴얼과 농협 포털사이트 신규 구축 및 운영사이트 이관 프로젝트에서 웹 퍼블리싱을 맡았습니다. 프레임아웃 소속으로 참여했습니다.

## Context

- 농협 최초의 포털사이트를 신규로 구축하는 프로젝트였습니다.
- 기존 운영사이트를 새 포털로 이관하는 작업이 함께 진행됐습니다.
- 콘텐츠는 Wizard CMS로 관리되어, 관리자 화면과 콘텐츠 관리 기능도 퍼블리싱 범위였습니다.

## Role

웹 퍼블리셔로 다음을 담당했습니다.

- 범농협 운영지원센터 2.0 리뉴얼 퍼블리싱
- 농협 포털사이트 신규 구축 및 운영사이트 이관
- Wizard CMS 기반 관리자 화면 및 콘텐츠 관리 기능 퍼블리싱

## Action

1. Pug와 SCSS로 컴포넌트 단위의 퍼블리싱 구조를 적용했습니다.
2. 반응형 웹과 웹 접근성을 고려해 UI를 구현했습니다.
3. 메인 페이지에는 GSAP 기반 모션 인터랙션을 적용해 UX를 개선했습니다.
4. Wizard CMS와 연계되는 관리자 화면을 퍼블리싱했습니다.

## Result

- 농협 최초 포털사이트 구축 프로젝트에 참여해 신규 서비스 UI를 구현했습니다.
- 모션 인터랙션과 시각 요소를 적용해 메인 페이지의 완성도를 높였습니다.
- 운영지원센터에 반응형과 웹 접근성을 적용해 다양한 환경에서 일관된 사용성을 제공했습니다.
- 컴포넌트 기반 구조로 유지보수성을 확보했습니다.
