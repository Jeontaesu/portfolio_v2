## 문제

관리자 CMS를 만들면서 글을 저장하고 삭제하는 동작을 Server Action으로 구현했습니다. 로그인한 관리자에게만 폼이 보이므로 안전하다고 생각하기 쉽지만, 그렇지 않습니다.

Server Action은 내부적으로 POST 엔드포인트입니다. 화면에서 버튼을 숨겨도 해당 요청을 보낼 수 있는 사람은 누구든 호출을 시도할 수 있습니다. 따라서 권한 확인은 UI가 아니라 서버의 각 진입점에서 해야 합니다.

세션 방식도 정해야 했습니다. 관리자는 1명이고, GitHub OAuth로 로그인하며, 비밀번호는 저장하지 않습니다.

## 원인과 선택지

권한을 확인하는 위치를 정할 때 레이아웃에서 한 번 검사하는 방법을 먼저 고려했습니다. 하지만 레이아웃은 클라이언트에서 이동할 때 다시 실행되지 않아 보안 경계가 될 수 없습니다. 그래서 Admin 레이아웃, 각 페이지, 모든 Server Action, 관리자 읽기 쿼리에서 각각 검사합니다.

세션은 JWT로 두었습니다. DB 세션을 쓰면 `Account`, `Session` 테이블이 필요한데, 관리자가 1명인 사이트에는 과합니다. 대신 JWT만 믿으면 관리자 권한을 회수해도 토큰이 만료될 때까지 접근이 유지된다는 문제가 있습니다.

## 해결

JWT는 "누가 로그인했는지"의 힌트로만 쓰고, 권한은 `requireAdmin()`이 요청마다 DB에서 확인합니다.

```ts
// 모든 Server Action의 첫 줄
export async function savePost(prev: FormState, formData: FormData) {
  const admin = await requireAdmin();
  // ... Zod 검증 → DB 저장 → revalidate
}
```

허용 목록은 환경 변수가 아니라 DB의 `User.role = ADMIN`입니다. GitHub 로그인 후 `signIn` 콜백이 이메일(대소문자 무시)로 ADMIN 행을 찾고, 없으면 `AccessDenied`로 돌려보냅니다. 코드를 수정하지 않고도 관리자를 추가하거나 제거할 수 있습니다.

### 로그인 리다이렉트 루프

JWT는 유효하지만 DB에서는 관리자가 아닌 사용자가 있을 수 있습니다. 로그인 페이지가 "JWT가 있으면 대시보드로 보낸다"고 판단하고, 대시보드는 "관리자가 아니면 로그인으로 보낸다"고 판단하면 두 페이지를 계속 오가게 됩니다. 로그인 페이지도 리다이렉트 없이 DB로 관리자 여부를 확인하는 `getAdmin()`을 쓰도록 해서 루프를 막았습니다.

## 선택 근거와 trade-off

- **비용**: 보호된 요청마다 DB 쿼리가 1건 늘어납니다. 관리자 1명이 쓰는 CMS라서 감수할 수 있다고 판단했습니다. 사용자가 많은 서비스라면 캐시나 세션 테이블을 다시 검토해야 합니다.
- **장점**: 권한을 회수하면 JWT 만료를 기다리지 않고 즉시 접근이 막힙니다.
- `next-auth` v5는 아직 베타(5.0.0-beta.32)입니다. `auth()` 헬퍼와 환경 변수 이름이 v5 규칙이라 선택했고, API가 바뀔 수 있다는 위험은 있습니다. 정식 버전이 나오면 업그레이드를 검토할 계획입니다.
- 오류 메시지는 "등록되어 있지 않습니다"와 일반 오류 두 가지만 보여 줘서, 허용 계정이나 실패 원인이 드러나지 않게 했습니다.

## 검증한 것과 하지 않은 것

실제 GitHub 로그인 없이 `AUTH_SECRET`으로 세션 쿠키를 만들어 `next start`에서 11개를 확인했습니다. 쿠키가 없거나 깨졌거나 DB에 없는 사용자, VIEWER는 로그인 페이지로 이동하고 ADMIN은 대시보드로 이동하며, 로그인 페이지에서 루프가 생기지 않습니다. GitHub OAuth 왕복(승인, 콜백, 세션)은 로컬과 Vercel 프로덕션에서 각각 로그인이 성공하는 것을 확인했습니다.

다만 Server Action을 권한 없는 상태에서 직접 호출하는 자동 테스트는 아직 없습니다. 모든 Action이 첫 줄에서 `requireAdmin()`을 부르는 것은 규칙으로만 지키고 있어서, 새 Action을 추가할 때 빠뜨리면 기계적으로 잡아 주는 장치가 없습니다.
